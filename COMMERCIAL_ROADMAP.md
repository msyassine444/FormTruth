# FormTruth — Commercial Roadmap (post-v1.0)

## v1.1 (next)
- Auto-fill assistant for MATCH fields (user-confirmed).
- Browser-native profiles sync (opt-in, still local-only by default).
- Optional OCR for image-only documents in backend.
- Wider country phone coverage via optional libphonenumber-js integration.
- More French/Arabic field edge cases from real-world form corpus.

## v1.2
- Optional encrypted profile export with user-held passphrase (real key management, off by default).
- Team/family shared templates (export/import only, no cloud).
- Headless-safe scan API for power users.

## v2.0 (exploration)
- Desktop companion app (Electron) with the same local-first engine.
- Form field name suggestions to site owners (B2B angle).
- Multilingual UI.

## Non-goals (by design)
- No cloud sync requirement.
- No analytics on personal data.
- No automatic form submission.
- No AI-based "guessing" of truth values — UNKNOWN stays UNKNOWN.
